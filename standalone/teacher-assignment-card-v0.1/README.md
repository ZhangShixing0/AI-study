# Teacher Assignment Card v0.1

独立教师布置卡工具，用于从结构化题目数据生成可预览、可导出的任务卡。它不依赖学生端或管理端运行，也不会进入生产服务器部署包。

## 使用

在本目录启动任意静态文件服务器后打开 `index.html`，例如：

```powershell
python -m http.server 8080
```

需要重建示例数据时，先检查 `build-data.py` 的输入约定，再运行 `node --test tests/*.test.js`。输入、导出图片和临时缓存均应保存在 Git 忽略范围内；真实学生信息不得写入示例数据或提交到仓库。

该工具当前作为独立成果随仓库维护，版本与主服务分别演进。
