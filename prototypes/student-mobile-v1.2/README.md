# Student Plan UI Asset Pack

This package is a static HTML prototype for the student daily plan page.

## Entry

Open `index.html` directly in a browser.

## Important

The `.placeholder.png` files are cropped from the reference image and upscaled only for temporary layout matching. They are **not final production assets**.

For the final UI, replace them with:

```text
assets/images/banner-student-study.png
assets/images/type-limit-green.png
assets/images/type-limit-purple.png
```

Final images should be high-resolution and should not contain baked-in UI text/buttons.
