# 学生手机端低保真页面规格 V0.1

## 1. 文档目的

本文档用于定义“考研数学每日督学系统”第一版学生手机端页面的核心使用流程、信息架构和低保真页面规格。

第一版目标是低成本跑通每日督学闭环：学生打开手机网页后，先截图保存今日学习计划，离开网页使用自己持有的教材做题，完成后回到页面按顺序提交做题反馈。

本文档不包含代码实现、数据库设计、AI 选题、每日 PDF、飞书实时读取、复杂错题订正或视觉动画。

## 2. 数据来源

当前规格参考真实样例文件：

- `data/samples/sample.xlsx`

样例工作簿包含两张表：

### 2.1 题型表 Sheet1

主要字段：

| 字段 | 页面用途 |
| --- | --- |
| 题型ID | 题型唯一标识，用于关联题目 |
| 排序码 | 今日题型展示和反馈开放顺序 |
| 科目 | 展示或后台筛选 |
| 大章节ID | 后台组织字段 |
| 大章节名称 | 学习单元展示辅助信息 |
| 内容板块 | 区分知识点、父级题型、子题型 |
| 题型名称 | 页面展示的题型标题 |
| 父级题型ID | 子题型归属 |
| 建议时长（天） | 后台排课参考 |
| 是否可直接布置 | 只有“是”的题型可进入学生今日计划 |
| 题型讲解图片 | 页面顶部展示原创题型讲解图片 |
| 录入说明 | 后台维护说明，不直接展示给学生 |

样例中存在“父级题型”行，例如 `求极限（重点）`，该行 `是否可直接布置` 为“否”，学生端不作为可反馈题型展示。

### 2.2 题目表 Sheet2

主要字段：

| 字段 | 页面用途 |
| --- | --- |
| 题目ID | 单题唯一标识 |
| 归属题型 | 关联题型表的 `题型ID` |
| 题型名称（核对用） | 后台核对，不优先作为页面主标题 |
| 题目备注 | 后台参考，学生端默认不展示 |
| 适用班型 | 后台筛选 |
| 计划适用阶段 | 后台筛选 |
| 资料来源 | 学生端题目来源展示，例如 `880`、`1000` |
| 原书位置展示文本 | 学生端题号展示来源 |
| 题型内排序 | 当前题型内题目排序 |
| 题面展示权限 | 第一版应为“仅显示题号” |

数据校验提示：样例题目表中出现 `归属题型 = G-01-Z-03`，但当前题型表样例未提供对应题型行。后续导入真实数据时，需要检查题目表中的 `归属题型` 是否都能在题型表中找到。

## 3. 不可修改业务规则

1. 学生每日打开页面后，顶部一次性看到今天全部学习单元、题型讲解图片和题号清单，便于截图保存后离开网页做题。
2. 顶部必须展示固定主文案：`请截图保存今日计划并投入学习！完成后及时反馈！`
3. 固定主文案上方展示后台可配置励志话术。
4. `今日学习计划` 标题右侧展示距离考研倒计时。
5. 页面左侧设置窄侧边条，入口顺序为：`今日计划`、`排行榜`、`能力曲线`。
6. 页面下方是反馈提交区，只开放当前顺序中的题型。
7. 每道题只能选择：`正确`、`错误`、`未作`。
8. 当前题型不存在 `未作` 时，提交后才能开放下一个题型。
9. 当前题型存在 `未作` 时：未作按错误计入正确率；该题型本次未完成；今日后续题型不再开放；下一学习日继续该题型未作内容。
10. `错误` 按错误计入正确率和错题记录，但不阻止开放下一题型。
11. 当前题型必须提供 `本题型全部未作` 快捷操作。
12. 学生确认完成今日反馈后，展示当天已提交题型的正确率结果。
13. 首七日内连续学习天数排行按“今日完成率是否达到 80%”计算。
14. 第一版不做 AI 选题、不生成每日 PDF、不实时读取飞书、不做复杂错题订正、不做动画炫技。

## 4. 核心操作路径

1. 学生用手机打开今日督学页面。
2. 页面顶部显示今日日期、学生身份、距离考研倒计时、后台配置励志话术和固定截图提示。
3. 学生在顶部一次性查看今天全部学习单元：
   - 题型名称
   - 原创题型讲解图片
   - 教材与题号清单
4. 学生截图保存今日计划。
5. 学生离开网页，使用自己持有的教材做题。
6. 学生做完后回到同一页面。
7. 页面下方只开放当前顺序中的一个题型反馈区。
8. 学生逐题选择 `正确`、`错误` 或 `未作`。
9. 如果当前题型全部未做，学生可点击 `本题型全部未作`。
10. 学生查看提交按钮上方的今日题型正确率概览。
11. 学生点击 `提交本题型反馈`。
12. 系统检查是否每道题都已选择。
13. 系统根据是否存在 `未作` 展示不同确认提示。
14. 学生确认提交。
15. 页面更新当前题型正确率。
16. 若当前题型不存在 `未作`，开放下一个题型。
17. 若当前题型存在 `未作`，锁定今日后续题型，并提示下一学习日继续当前题型未作内容。
18. 页面底部展示首七日内连续学习天数排行。
19. 学生可通过左侧侧边条跳转到 `今日计划`、`排行榜`、`能力曲线` 区域。

## 5. 手机端页面信息架构

设计宽度以 390px 为主，兼容 375px 至 430px 手机宽度。页面采用单列纵向布局。

页面左侧保留窄侧边条，右侧为主要内容。侧边条承担主视图切换，不改变“今日计划视图顶部一次性展示今日全部学习单元”的核心规则。

侧边条入口顺序固定为：

```text
今日计划
排行榜
能力曲线
```

侧边条交互：

- 点击 `今日计划`，显示今日学习计划、题号清单、反馈提交和今日反馈结果。
- 点击 `排行榜`，单独显示首七日内连续学习天数排行视图。
- 点击 `能力曲线`，单独显示能力曲线视图。
- 当前视图对应的侧边条入口显示选中态。
- 侧边条不承载二级菜单，不增加复杂操作。

### 5.1 今日信息区

页面顶部展示：

```text
今日学习计划              距考研 195 天
2026年X月X日  张同学
状态：待反馈
```

说明：

- `今日学习计划` 位于标题区左侧。
- `距考研 X 天` 位于标题区右侧，以小型强调标签展示。
- 倒计时目标日期由后台配置，不在前端写死。
- 倒计时计算口径：`考研日期 - 当前日期`，当天未结束时仍显示剩余自然日。
- 如果后台未配置考研日期，显示 `距考研 -- 天`。

状态可包含：

- `待反馈`
- `进行中`
- `今日已完成`
- `今日未完成`

### 5.2 励志话术与截图提示区

展示顺序固定为：

```text
稳住节奏，今天也只需要完成眼前这一组。

请截图保存今日计划并投入学习！完成后及时反馈！
```

说明：

- 第一行励志话术由后台配置。
- 第二行是固定主文案，应作为一行小字提示，不加额外小字说明。
- 该区必须出现在首屏靠前位置。

### 5.3 今日全部学习单元区

该区域必须展示今天全部题型，即使下方反馈区当前只开放第一个题型。

每个题型展示：

```text
题型 1：函数极限概念辨析（注意复合函数极限）
[原创题型讲解图片]

《880》第一章-基础：
选择题 2、4、5
填空题 3、5
```

字段映射：

- `题型名称` 来自题型表 `题型名称`
- 原创题型讲解图片来自题型表 `题型讲解图片`
- 教材来源来自题目表 `资料来源`
- 教材位置与题号来自题目表 `原书位置展示文本`

题号展示要求：

- 不展示第三方教材完整题面图片。
- 不展示题目完整文本。
- 只展示学生需要完成的书名、章节、层级、题型和题号。
- 页面文案优先整理为聚合格式：`《资料来源》章节-层级：题目类型 题号`

样例数据当前可由 `原书位置展示文本` 得到：

```text
《880》第1章基础一第4题
《880》第1章基础一第5题
《880》第1章基础一第10题
```

如果后台数据能拆分出题目类型，则静态原型展示为：

```text
《880》第一章-基础：
选择题 4、5、10
```

若暂时无法从数据中稳定拆分题目类型，原型中不得自动猜测，可先使用原书位置展示文本列表。

### 5.4 当前题型反馈区

不设置单独的“做题反馈区标题”。当前题型反馈区标题直接写：

```text
请按顺序填写今日做题情况
```

反馈区展示：

```text
当前开放：题型 1 / 共 3 个题型
题型名称：函数极限概念辨析（注意复合函数极限）

[本题型全部未作]

《880》第1章基础一第4题
[正确] [错误] [未作]

《880》第1章基础一第5题
[正确] [错误] [未作]
```

题目排序：

- 按题目表 `题型内排序` 升序展示。
- 只展示当前开放题型的题目反馈控件。
- 后续题型未开放时，不展示可点击反馈控件。

### 5.5 今日题型正确率概览

该区放在 `提交本题型反馈` 按钮上方。

展示规则：

- 每个题型一个小饼图。
- 未提交题型显示灰色圆形。
- 已提交题型显示正确率饼图。
- 饼图下方显示 `题型1`、`题型2`、`题型3` 和正确率或 `未提交`。
- 如果今日只有一个题型，饼图居中。
- 如果今日有多个题型，一行最多展示 3 个，超过 3 个换行。

未提交状态：

```text
今日题型正确率

○        ○        ○
题型1    题型2    题型3
未提交   未提交   未提交
```

提交题型 1 后：

```text
今日题型正确率

◔        ○        ○
题型1    题型2    题型3
75%      未提交   未提交
```

### 5.6 提交按钮

当前题型反馈区底部展示主按钮：

```text
[提交本题型反馈]
```

按钮宽度建议占满内容区域，最小高度 44px。

### 5.7 今日反馈结果区

展示当天已提交题型结果。

未提交前：

```text
今日反馈结果
暂无提交结果
```

提交后：

```text
今日反馈结果

题型1：函数极限概念辨析
正确 5｜错误 2｜未作 0｜正确率 71%
```

说明：

- 正确率 = 正确数 / 当前题型题目总数。
- `错误` 和 `未作` 都按错误计入正确率。
- `未作` 额外影响今日后续题型是否开放。

### 5.8 首七日内连续学习天数排行

排行榜作为独立视图展示，只有点击左侧侧边条 `排行榜` 后才显示。

标题固定为：

```text
首七日内连续学习天数排行
```

排行口径：

```text
今日完成率 = 非未作题数 / 今日总题数
```

计算规则：

- `正确` 算已完成。
- `错误` 算已完成。
- `未作` 不算已完成。
- 今日完成率达到 80%，计入连续学习天数。
- 今日完成率低于 80%，不计入连续学习天数。

未提交前：

```text
首七日内连续学习天数排行
提交反馈后查看排行
```

提交后且达到 80%：

```text
首七日内连续学习天数排行

我的今日完成率：85%
我的连续学习：3天
我的排名：第8名

1. 王同学  7天
2. 李同学  6天
3. 陈同学  6天
```

提交后但未达到 80%：

```text
首七日内连续学习天数排行

我的今日完成率：60%
今日未达成连续学习标准
完成今日 80% 以上题目后计入连续学习天数
```

### 5.9 能力曲线

能力曲线作为独立视图展示，只有点击左侧侧边条 `能力曲线` 后才显示。

V0.1 只做低保真展示，不做复杂能力诊断。建议先展示最近若干次学习反馈形成的简化趋势，例如：

```text
能力曲线

近7次题型正确率趋势
[简化折线占位]

当前展示：已提交题型正确率
```

说明：

- 能力曲线不影响今日计划和反馈提交流程。
- V0.1 不做 AI 能力分析，不生成复杂标签。
- 若历史数据不足，展示：`完成更多学习反馈后生成能力曲线`。

## 6. 关键按钮与反馈

### 6.1 正确

位置：每道题反馈行下方或右侧的三选一按钮组。

点击后：

- 当前题标记为 `正确`。
- 同一题的 `错误`、`未作` 取消选中。

### 6.2 错误

位置：每道题反馈行下方或右侧的三选一按钮组。

点击后：

- 当前题标记为 `错误`。
- 该题提交后计入正确率和错题记录。
- 不阻止下一个题型开放。

### 6.3 未作

位置：每道题反馈行下方或右侧的三选一按钮组。

点击后：

- 当前题标记为 `未作`。
- 提交后按错误计入正确率。
- 只要当前题型存在至少一个 `未作`，今日后续题型不再开放。

### 6.4 本题型全部未作

位置：当前题型名称下方、题目列表上方。

点击后：

- 当前题型所有题目批量标记为 `未作`。
- 不自动提交。
- 显示轻提示：`已将本题型全部标记为未作`。

### 6.5 提交本题型反馈

位置：当前题型反馈区底部，位于今日题型正确率概览下方。

点击后：

- 若存在未选择题目，提示：`还有题目未选择，请完成后再提交`
- 若不存在 `未作`，展示确认：`确认提交本题型反馈？提交后将开放下一个题型。`
- 若存在 `未作`，展示确认：`本题型存在未作。未作将按错误计入正确率，今日后续题型不再开放，下一学习日继续当前题型未作内容。确认提交？`

确认弹窗按钮：

- `返回检查`
- `确认提交`

## 7. 三种核心场景行为

### 7.1 当前题型全部完成

条件：

- 当前题型所有题目都选择了 `正确` 或 `错误`。
- 不存在 `未作`。

提交后：

- 当前题型标记为已提交。
- 当前题型饼图渲染正确率。
- 今日反馈结果区新增该题型结果。
- 下一个题型开放。
- 若当前题型是今日最后一个题型，则展示 `今日反馈已完成`。

### 7.2 当前题型部分错误但没有未作

条件：

- 至少一道题选择 `错误`。
- 没有题目选择 `未作`。

提交后：

- 错误题计入错题记录。
- 错误题按错误计入正确率。
- 当前题型饼图渲染正确率。
- 下一个题型开放。
- 页面提示：`本题型已提交，错误题已记录`。

### 7.3 当前题型存在未作

条件：

- 至少一道题选择 `未作`，或点击了 `本题型全部未作`。

提交前：

- 确认弹窗必须说明未作后果。

提交后：

- 未作按错误计入正确率。
- 当前题型标记为本次未完成。
- 当前题型饼图渲染正确率。
- 今日后续题型全部锁定。
- 后续题型饼图保持灰色未提交。
- 页面提示：`今日后续题型不再开放，下一学习日继续当前题型未作内容`。

## 8. 易误提交点与最小避免方式

| 易误点 | 避免方式 |
| --- | --- |
| 学生误点 `本题型全部未作` | 只批量选中，不自动提交；提交时二次确认 |
| 学生不知道 `未作` 会阻断后续题型 | 选择未作后，提交确认中明确写出后果 |
| 学生漏选题目 | 提交时强校验，未选择则不允许提交 |
| 学生误以为 `错误` 会阻断后续题型 | 在确认或反馈结果中提示错误不阻止下一题型 |
| 学生提交后想修改 | 确认弹窗增加：`提交后不可自行修改，请检查后再提交` |
| 学生没有截图就离开 | 励志话术和固定截图提示必须出现在顶部靠前位置 |
| 侧边条让学生误以为可以先看排行榜再做题 | 排行榜作为独立视图，未提交前仅显示 `提交反馈后查看排行` |
| 能力曲线让学生误以为有 AI 诊断 | V0.1 文案只写 `已提交题型正确率趋势`，不写智能分析 |

## 9. 静态原型页面规格

### 9.1 尺寸与布局

- 主设计宽度：390px
- 兼容范围：375px 至 430px
- 左侧窄侧边条 + 右侧内容区
- 侧边条宽度：48px 至 56px
- 内容区左右边距：12px 至 16px
- 区块间距：16px 至 24px
- 按钮最小高度：44px
- 不使用动画
- 不使用复杂视觉装饰
- 视觉风格应清爽、年轻、专业，有考研学习氛围，接近优秀在线教育 SaaS 产品。

## 10. 原型制作注意事项

1. 顶部计划区必须完整展示今日全部题型，不能因为反馈顺序而隐藏后续题型。
2. 题型讲解图片只能使用原创图片，不展示第三方教材完整题目图片。
3. 学生端展示题号即可，学生使用自己持有的教材做题。
4. 当前反馈区一次只开放一个题型。
5. `未作` 是关键阻断行为，必须在确认弹窗中说明清楚。
6. 今日题型正确率概览放在提交按钮上方。
7. 只有一个题型时，正确率饼图居中。
8. 排行榜作为独立视图，不抢占今日计划和反馈区。
9. 能力曲线作为独立视图，不干扰当日学习反馈主流程。
10. 左侧侧边条只做主视图切换，不做复杂菜单。
11. 页面风格应克制、清晰，适合学生每天重复使用。

## 11. 待确认项

1. 题目表是否会新增结构化字段用于区分 `选择题`、`填空题`、`计算题`，还是完全依赖 `原书位置展示文本`。
2. 已提交反馈后，学生是否允许在当天自行修改。V0.1 建议不允许自行修改。
3. 今日完成率达到 80% 的计算分母是否为“今日全部题目数”。V0.1 暂按今日全部题目数计算。
4. 排行榜是否只展示前 3 名和我的排名。V0.1 建议只展示前 3 名和我的排名。
5. 若题型表存在父级题型，学生端是否完全隐藏父级题型。V0.1 暂按隐藏处理，只展示可直接布置题型。
6. 考研倒计时的目标日期由后台统一配置，还是按学生目标考试年份分别配置。
7. 能力曲线的指标口径是否只使用题型正确率。V0.1 暂按“已提交题型正确率趋势”展示。
