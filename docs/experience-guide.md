# 学生端体验指南

内置体验模式适合先看产品如何工作。它使用静态合成数据，可以演示反馈提交和页面变化，不需要学生账号，也不连接教师后台。

## 启动

安装 Python 后，在仓库根目录运行：

```powershell
python -m http.server 8094 --bind 127.0.0.1 --directory prototypes/student-mobile-v3.3
```

打开 <http://127.0.0.1:8094/>，在欢迎页点击「立即体验」。结束时在终端按 `Ctrl+C` 停止服务。如果端口被占用，可以将命令与访问地址中的 `8094` 一起改成其他空闲端口。

## 体验一次学习反馈

1. 在「今日计划」查看题型说明和习题来源，确认书目、章节及题号。
2. 向下滚动到「做题反馈」。为第一题选择「正确」，为第二题选择「错误」，再选择一个错因，例如「计算错」。
3. 点击「提交本题型反馈」。演示页面会显示「今日已完成」以及章节小结。
4. 点击底部「成长」，查看预置的学习热力图、章节掌握度和错因诊断。
5. 还可以切换「自习室」和「我的」了解页面结构。

图表使用预置样例；提交演示反馈不等于重新计算真实学习指标。刷新页面后重新点击「立即体验」，可恢复初始体验状态。体验模式不会保存正式学习记录，也不会记录真实自习时长。

## 运行完整系统

学生账号、真实反馈持久化与教师后台需要后端服务。请按 [README 快速开始](../README.md#快速开始)初始化本地样例数据库并启动应用。

教师工作台和任务图工具也可先通过 [项目介绍视频](../README.md#项目介绍视频)了解，相关画面从 01:00 开始。
