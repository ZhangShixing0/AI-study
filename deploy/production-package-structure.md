# 生产包与服务器目录边界

## 仓库负责

- 应用代码与当前前端版本。
- 公共种子、结构定义和校验工具。
- 不含秘密值的配置模板。
- 部署包生成、验证和冒烟脚本。

## 部署包负责

部署包是仓库运行时文件的最小快照。它不携带开发文档、测试、截图、缓存、独立演示工具或本地数据库。

## 服务器负责

以下内容由服务器在仓库和部署包之外管理：

- `.env` 与所有秘密值。
- PostgreSQL 数据、上传文件和运行日志。
- 数据库与部署包备份。
- 反向代理、TLS、进程管理、监控和告警配置。

更新时只替换包内代码。不得覆盖服务器持有的配置、数据库或备份；具体步骤见 `production-safe-update-runbook.md`。
